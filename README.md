### 🛡️ What I do

I build security tooling for the AI-agent era — scanners that read what an agent (or a website) actually exposes, **before an attacker does**. Day to day: SecOps and threat research. The rest of the time: **[PALANIT](https://palanit.com)**, a security portal for AI agents and their tools.

- 🔭 Building **[PALANIT](https://palanit.com)** — passive scanners for MCP servers, agent manifests and websites, a verification/badge layer, and CI tooling.
- 🧰 Shipped **[`palanit-core`](https://github.com/stasxr/palanit-core)** (open-source MCP/agent scanner, on PyPI) and the **[PALANIT Security Check GitHub Action](https://github.com/marketplace/actions/palanit-security-check)**.
- 🔬 Into: MCP/agent supply-chain, tool poisoning & prompt injection, web + email hardening, incident response.
- 📨 Reach me at **[palanit.com](https://palanit.com)** · [Telegram](https://t.me/p41anitx)
